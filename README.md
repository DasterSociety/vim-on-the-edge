# Embedded Vim Config

A lightweight, fast, and plugin-free Vim configuration optimized for embedded Linux boards.

This configuration is designed for systems like **BeagleBoard, Raspberry Pi, Jetson Nano, Orange Pi**, and other low-resource or legacy Linux environments where modern Neovim or plugin-based workflows may not be available.

It provides a clean editing experience with syntax highlighting, essential key mappings, improved navigation, and smart defaults — all **without requiring any plugins**.

---

## ✨ Features

- ✔ **Zero plugins** — 100% Vimscript, works even on very old versions of Vim
- ✔ **Syntax highlighting** for common languages (C, Python, Bash, etc.)
- ✔ **Fast escape** using `jk` in insert mode
- ✔ Improved UI: line numbers, relative numbers, cursorline
- ✔ Smart indentation for Python, C/C++, and shell scripts
- ✔ Enhanced search behavior (incremental search, smartcase)
- ✔ Quick-save/quit key mappings
- ✔ Highlights trailing whitespace
- ✔ Extremely lightweight — ideal for low-resource embedded systems
